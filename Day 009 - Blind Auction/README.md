# 📅 Day 9: Dictionaries, Nesting & The Secret Auction

## 🎓 Course Metadata
- **Course:** 100 Days of Code Python  
- **Difficulty:** ⭐

## 📌 Overview
Day 9 introduced Python dictionaries and how to work with structured data using key–value pairs. The lesson also covered nesting dictionaries and lists to model complex data, culminating in a blind auction program that determines a winner based on user bids.

## 🧠 Key Concepts
- Creating and using dictionaries
- Retrieving values with keys and `get()`
- Adding and updating dictionary items
- Looping through keys, values, and items
- Nesting lists and dictionaries for structured data
- Using dictionaries to track dynamic user input

## 🛠️ Functions & Features Practiced
- Dictionary creation and mutation
- `dict[key]` and `dict.get()`
- `keys()`, `values()`, and `items()`
- Looping through dictionaries
- Nested data structures (list ↔ dictionary)
- Custom helper functions
- Conditional logic with loops

## 🎯 Project of the Day

### 🔨 Blind Auction
A command-line blind auction program that collects bids from multiple users and determines the highest bidder.

**Highlights:**
- Stored bidder names and amounts in a dictionary
- Used a loop to accept multiple bidders
- Cleared the console between entries for privacy
- Implemented a function to find the highest bid
- Displayed the final winner and winning amount

This project reinforces dictionary manipulation, looping logic, and real-world data modeling.

## ✅ Outcomes
- Developed a strong understanding of dictionaries and key–value access
- Learned how to safely retrieve, add, and update dictionary data
- Practiced looping through dictionaries effectively
- Gained confidence working with nested data structures
- Built a complete interactive program using dictionaries as the core data store
