# 📅 Day 10: Functions With Outputs

## 🎓 Course Metadata
- **Course:** 100 Days of Code Python  
- **Difficulty:** ⭐

## 📌 Overview
Day 10 focused on writing functions that return values using the `return` statement. The lesson emphasized how returned data can be reused in calculations, stored in variables, and chained into more complex logic. Additional topics included string formatting with `title()` and documenting code using docstrings.

## 🧠 Key Concepts
- Returning values from functions
- Using returned results in further operations
- Multiple return values (tuple unpacking)
- String formatting with `title()`
- Writing meaningful docstrings for documentation
- Building reusable function-based systems

## 🛠️ Functions & Features Practiced
- `return` statement
- Functions with single and multiple outputs
- Tuple unpacking from returned values
- `str.title()`
- Docstrings using triple quotes `""" """`
- Storing functions inside dictionaries
- Calling functions dynamically

## 🎯 Project of the Day

### 🧮 Calculator
A reusable command-line calculator that performs basic arithmetic operations.

**Highlights:**
- Created separate functions for add, subtract, multiply, and divide
- Stored functions inside a dictionary for dynamic operation selection
- Used returned values for continuous calculations
- Implemented recursion to restart the calculator
- Practiced clean function-based architecture

This project reinforces returning values, function reuse, and building modular programs.

- Gained strong understanding of functions with outputs
- Learned how returned values drive program logic
- Practiced writing readable and documented functions
- Built a structured, multi-operation calculator
