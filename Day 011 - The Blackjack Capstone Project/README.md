# 📅 Day 11: The Blackjack Capstone Project

## 🎓 Course Metadata
- **Course:** 100 Days of Code Python  
- **Difficulty:** ⭐

## 📌 Overview
Day 11 was a capstone project that combined everything learned so far: functions, loops, conditionals, lists, and randomness. The goal was to build a fully functional Blackjack game that simulates a real casino-style experience in the terminal.

## 🧠 Key Concepts
- Modular function design
- Game loop control with `while`
- Conditional game outcome logic
- Score calculation and edge case handling
- Representing game state using lists
- Using randomness to simulate card dealing

## 🛠️ Functions & Features Practiced
- Custom helper functions (`deal_card()`, `calculate_score()`, `compare()`)
- `random.choice()` for card selection
- `sum()` for score calculation
- Handling special cases (Blackjack = `0`)
- Adjusting Ace value (11 → 1) dynamically
- Loop-based gameplay flow
- Restart logic with recursion and input control

## 🎯 Project of the Day

### 🃏 Blackjack
A complete command-line Blackjack game following simplified casino rules.

**Highlights:**
- Simulated an unlimited deck using a predefined card list
- Implemented Ace logic (11 or 1 depending on score)
- Represented Blackjack as a special score value (`0`)
- Created dealer logic (draw until score ≥ 17)
- Compared user and dealer scores to determine outcomes
- Added replay functionality for continuous gameplay

This project reinforces structured programming, game logic implementation, and real-world rule simulation.
